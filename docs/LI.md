# Share Agent While True

For maintainers writing a release post. Adapt the voice; keep the boundaries.
Use a versioned, privacy-safe image and link the actual release being shared.

## Short post

Your coding agent hit a usage limit. Do you really need to babysit its terminal?

Agent While True brings local Codex CLI and Claude Code sessions into one KDE
Konsole dashboard: quota windows, reset times, exact one-time permissions and
guarded continuation when supported sessions can resume.

The dashboard now shows what this watch did: permission answers sent, budget
restarts verified and provider waits armed. Plain-language history explains what
happened without exposing your terminal contents.

It does not buy credits, change models or guess answers to unknown questions.
Python 3.14, zero third-party runtime dependencies, GPL-3.0-or-later, and the same
tested release gate locally and on GitHub. The optional CGA theme is for the soul.

Try it in observe mode, star it if it helps, or fork it with a tested prompt
fixture: [Agent While True on GitHub](https://github.com/marcelpetrick/AgentWhileTrue).

## Before publishing

- Link the green tagged release, not an unverified development version.
- Label scripted demos as invented data; never share live account or task data.
- Say "verified budget restarts", not "tasks completed" or "hours saved".
- Never claim all prompts, all terminals or every future provider version work.
- Invite a useful first contribution: a redacted blocker, test, or clearer doc.
